# Millstone MPC

An 8-voice hybrid synth for **Akai MPC standalone** devices (Gen2 / aarch64, such as the MPC Key 37 Gen 2). It runs inside
the MPC's own plugin host as a native VST2, with a touchscreen page for every section. This is the MPC-only build of
[Millstone](https://github.com/dominikglaser/millstone); the macOS plugin lives in that separate repo.

> **Status: in development, not yet tested on hardware.** Built for MPC OS 3.x (glibc 2.39). Installing third-party plugins on
> a standalone MPC is unofficial and done at your own risk.

Each voice has **three Mutable Instruments Plaits macro-oscillators** (all 24 models; OSC 1 can also be **Elements**), a **24 dB
ladder filter** (low-pass or high-pass), **VCA and modulation ADSR envelopes**, and a **VCA** with ENV / LPG / ON modes. Around
the voices are **two LFOs**, **Tides**, **eight Euclidean clocks** and a **patch bay** with 12 cords, 26 sources and 46
destinations. After them comes a rack of **phaser, chorus, tape echo and reverb**. There is no sequencer or arpeggiator: drive it
from the MPC's sequencer, pads and keys.

It comes with 700 synth presets and 40 FX presets.

## Signal flow

```
                 ┌─ OSC 1 (Plaits or Elements) ─┐
 MIDI note ──────┼─ OSC 2 (Plaits) ─────────────┼─ mix (+ noise) ─ drive ─ LADDER VCF (LP/HP) ─ VCA ─┐
                 └─ OSC 3 (Plaits) ─────────────┘                               ▲              ▲     │
                                                         ENV, LFO or LFO 2 ─────┘    ENV/LPG/ON┘     │
                                                                                                     │
   x8 voices ─ volume ─ phaser ─ chorus ─ tape echo ─ reverb ─ OUTPUT ─ out  ◄───────────────────────┘

 LFO, LFO 2 (tri/sqr/saw/ramp/S&H, 0.01–350 Hz or tempo-synced) ──► VCF, TIMBRE CV, MORPH CV, patch bay
 LFO also ──► vibrato (OSC MOD)
 VCA ADSR ──► VCA (ENV mode)
 MOD ADSR ──► VCF (MOD SOURCE = ENV), FM (pitch per oscillator), TIMBRE/MORPH CV (CV SOURCE = ENV)
 Tides, clocks, RANDOM, velocity, pressure, wheel, key, gate, oscillators, noise ──► patch bay
```

VCA modes: **ENV** shapes every note with the VCA ADSR. **LPG** patches TRIG into Plaits' own low-pass gate (LPG DECAY /
COLOUR), like a hardware trigger input: pings, plucks, drums. **ON** opens the VCA for as long as the key is held. In every
mode the self-enveloped models (6-op FM, string, modal, bass drum, snare, hi-hat) receive a gate from the keys.

MIDI: notes with velocity, mod wheel (CC 1, scaled by WHEEL > LFO), sustain pedal (CC 64), channel and polyphonic aftertouch,
pitch bend (BEND RANGE), all notes off.

## The code

`src/millstone.cpp` is the engine, `src/fx/` the effects chain, and `src/third_party/eurorack` the vendored Mutable DSP.
`vst/params.json` is the single source of truth for parameters; `vst/layout.conf` is the touchscreen skin; the presets are
generated by the Python scripts beside them. The plugin is built through the [Open MPC port kit](https://github.com/open-mpc/mpc-vst-plugins),
which wraps the shared engine as a VST2 and draws the skin as native MPC pages.

```sh
# needs a checkout of open-mpc/mpc-vst-plugins at ../mpc-vst-plugins (or set MPC_VST)
python3 "$MPC_VST/tools/gen_vst.py" vst/vst.json --params-h   # parameters
vst/build_zig.sh aarch64                                      # Gen2 .so (Zig; no Docker)
tools/run_tests.sh                                            # engine, fx and fuzz checks
```

This build differs from the macOS Millstone in two ways: the full engine (Elements, Tides, the clocks) is always compiled in
(the `MILLSTONE_FULL` flag), and the effects run inside the shared engine rather than in a host, so there is no JUCE.
